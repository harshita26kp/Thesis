# Explainable AI for Image Classification using ResNet50

## Project Overview

This repository contains the implementation and experiments for my bachelor's thesis on Explainable Artificial Intelligence (XAI) in Computer Vision.

The project investigates how different explainability techniques can identify the image regions responsible for the predictions made by a convolutional neural network.

## Thesis Topic

**A Comparative Evaluation of Explainable AI Techniques in Computer Vision**

## Objectives

- Train and evaluate a CNN for image classification.
- Use a pretrained ResNet50 model.
- Apply explainability methods to visualize model decisions.
- Compare the effectiveness of different XAI techniques.

## Dataset

- **Food-101**
- 101 food categories
- 101,000 images
- Used for image classification experiments.

## Model

- ResNet50 (pretrained on ImageNet)

## Explainability Methods

- Grad-CAM
- Grad-CAM++
- Score-CAM
- Ablation-CAM
